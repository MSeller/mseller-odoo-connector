# MSeller DGII e-CF Connector for Odoo

Community-maintained Odoo add-on that connects an Odoo company to
the [MSeller](https://mseller.app) DGII e-CF API so it can push
electronic invoices (e-CF) to the Dominican Republic's
[DGII](https://dgii.gov.do).

This repository is in active development. See the open pull
requests for the foundation module and the roadmap.
